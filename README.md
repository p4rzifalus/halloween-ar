# AR-постер «Хэллоуин»

Наведи камеру телефона на напечатанный постер — над ним послойно выдвигается объёмная сцена: Фредди, рука с когтями, тексты, ребята. QR-код в углу постера ведёт на сайт. Внизу появляется кнопка «Купить билет».

**Сайт:** https://p4rzifalus.github.io/halloween-ar/
**Без камеры:** https://p4rzifalus.github.io/halloween-ar/?preview

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Страница: сразу включает камеру, кнопка «Без камеры» в углу, кнопка «Купить билет» |
| `poster3d.js` | Сборка слоёв на three.js, объём, анимация появления |
| `preview.js` | Режим без камеры: параллакс от мыши или наклона телефона |
| `assets/layers.json` | Калибровка сцены — меняй цифры здесь, код трогать не нужно |
| `assets/poster.mind` | Метка MindAR, по которой распознаётся постер |
| `assets/*.png, *.jpg` | Слои из Figma |

Локально, не попадают на GitHub:

| Папка | Что там |
|---|---|
| `print/` | `qr.png`, `qr.svg` — QR на сайт |
| `source/` | `poster-print.png` — печатный файл из Figma, `poster-print-700.png` — он же для сборки `poster.mind`, `figma/` — выгрузки слоёв |

## Калибровка (`assets/layers.json`)

- `W`, `H` — размер макета в пикселях (Figma ×2), 1190×1684.
- `cameraDistance` — расстояние до телефона в ширинах постера (сейчас 4). Больше — слои крупнее.
- У каждого слоя: `x`, `y`, `w`, `h` — положение в пикселях макета; `z` — высота над бумагой в ширинах постера; `shadow` — сила тени; `bulge` — выпуклость; `thickness` — толщина торца.

Слой `plate` — фон. В режиме камеры он не рисуется: фоном служит сама печать.

## Если поменялся макет

Нужно пересобрать `assets/poster.mind` из нового печатного файла — см. README в корне папки `AR-posters`.

## Библиотеки

Грузятся с CDN jsdelivr: three@0.160.0, mind-ar@1.2.5. Сборки нет, это чистая статика на GitHub Pages.
